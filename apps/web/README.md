# apps/web — Boutique publique (Phase 3)

Application Next.js 15 (App Router) qui reprendra l'identité visuelle validée :

- accueil, catalogue, fiche produit, panier, checkout ;
- compte client, adresses, favoris, suivi de commande ;
- PWA installable, mode hors ligne, notifications push ;
- SEO : métadonnées, JSON-LD, sitemap, redirections 301 depuis l'ancien site statique.

Le design system sera partagé via `packages/ui`.
